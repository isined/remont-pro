Ремонт квартир под ключ — RemontPro

Сайт-визитка строительной компании, специализирующейся на ремонте квартир в Улан-Удэ. 
Проект включает в себя описание этапов работ, портфолио выполненных проектов, интерактивный калькулятор стоимости ремонта и форму обратного звонка с отправкой данных на электронную почту.

## 🌟 Основные возможности
- **Калькулятор стоимости:** динамический расчет цены ремонта в зависимости от площади и типа работ.
- **Форма обратной связи:** модальное окно с валидацией номера телефона и реальной отправкой заявок через сервис Formspree.
- **Панель доступности (Accessibility):**
  - Версия для слабовидящих (высококонтрастный режим).
  - Озвучивание текста при наведении курсора (Web Speech API).
  - Переключение на английский язык без перезагрузки страницы.
  - Переключение темной и светлой темы.

## 🛠 Технологии
- **HTML5** (семантическая верстка)
- **CSS3** (Flexbox, CSS Grid, адаптивность под мобильные устройства, анимации, CSS-переменные для тем)
- **JavaScript** (Vanilla JS, работа с DOM, API браузера, fetch-запросы)
